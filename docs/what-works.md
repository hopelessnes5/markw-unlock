## Рабочие приёмы

- **Временный root:** CVE-2019-2215 (`bhsu98`) на стоке Android 6.
- **TWRP:** прошивка образа в `recovery` через `dd ... bs=4096`; стартовая установка ROM — TWRP 3.4.0-1 (brotli), далее обновление до 3.7.0.
- **Снятие шифрования:** `mke2fs -t ext4 -m 0 -L data /dev/block/bootdevice/by-name/userdata`.
- **Установка ROM:** `twrp install <zip>`.
- **Установка Magisk:** `adb shell 'twrp sideload'` на устройстве + `adb sideload Magisk-v26.1.apk` на ПК.
- **ADB в TWRP:** устройство в состоянии `recovery`; ожидание готовности — опросом (`getprop`/`adb devices`), не `adb wait-for-device`.

## Состояние загрузчика (наблюдаемое)

После установки: `ro.boot.verifiedbootstate=green`, `ro.boot.flash.locked=1` — при этом система и root работают в рамках использованной схемы. **Не выполнять `fastboot oem lock` и не перепрошивать `aboot` без веской причины.**

# Обзор: ROM и recovery для markw (заметки)

> Снимок соображений на момент исследования. Актуальность сборок/ссылок проверяйте отдельно перед прошивкой.

## Прошивки (упомянутые в обзоре)

- **LineageOS 18.1 (Android 11)** — использована в данном репозитории: `18.1-20260901-UNOFFICIAL-markw` (Revived/UNOFFICIAL), стабильная работа в нашем кейсе.
- **LineageOS 22.2** и другие новые ветки — потенциально доступны сообществу, но требуют совместимого recovery/ядра/разметки; в этом репозитории не тестировались.
- **crDroid 7.x / 11.x** — упоминались как варианты для markw; совместимость и актуальность сборок нужно проверять на форумах/релизах мейнтейнеров.

## Recovery

- **TWRP 3.0.2-2** — устаревший, нет brotli (`E1001` на современных zip).
- **TWRP 3.4.0-1** (redispade) — рабочий минимум для установки ROM в нашем пути; на APK Magisk давал digest verification failed → использован sideload.
- **TWRP 3.7.0_12-1** (SonicBSV, 18.11.2023) — актуальный в нашем финальном состоянии, прошит в `recovery`.
- **OrangeFox R12.0 (Unofficial, 30.08.2026)** — упоминался как самый свежий вариант для markw; требует отдельной проверки совместимости с вашей ROM/разметкой (dynamic partitions и т.п.). Ссылка: https://sourceforge.net/projects/recovery-for-xiaomi-devices/files/markw/OrangeFox-R12.0-Unofficial-markw.zip/download

## Рекомендация

Для воспроизведения описанного пути использовать связку **TWRP 3.4.0-1 (установка) → 3.7.0 (финал) + LineageOS 18.1 + Magisk 26.1** и проверенные хэши из [files/CHECKSUMS.md](../files/CHECKSUMS.md). Любые отклонения (другая ROM/recovery) — отдельный риск-профиль.
